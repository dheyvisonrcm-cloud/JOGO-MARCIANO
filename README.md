# 👽 Jogo do Marciano

Um jogo de adivinhação em Java onde o jogador precisa descobrir em qual árvore (de 1 a 100) o marciano está escondido.


## 🎮 Como Jogar

1. Escolha uma opção no menu principal:
   - **1** - Jogar
   - **2** - Ver recorde
   - **3** - História e Regras do jogo
   - **4** - Sair

2. Ao jogar, escolha o nível de dificuldade:
   - **[D] Difícil** - 7 tentativas
   - **[M] Médio** - 8 tentativas
   - **[F] Fácil** - 10 tentativas

3. Digite um número de 1 a 100 para tentar acertar onde o marciano está escondido.

4. A cada tentativa, o jogo informa se o marciano está em uma árvore de número **maior** ou **menor**.

5. Se você acertar com menos tentativas que o recorde atual, digite seu nome para registrar o novo recorde.

## ⚙️ Funcionalidades

- Menu interativo com múltiplas opções
- Três níveis de dificuldade (Difícil, Médio, Fácil)
- Dicas a cada tentativa (maior/menor)
- Contador de tentativas
- Sistema de recorde com persistência em arquivo (`recorde.txt`)
- Introdução com história do jogo
- Tratamento de opção inválida no menu
